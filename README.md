Integração de Dados com MySQL Azure e Transformação com Power BI

Descrição

Projeto desenvolvido durante o curso da DIO com o objetivo de integrar dados de um banco MySQL ao Power BI, realizar transformações utilizando Power Query e construir visualizações para análise dos dados.

Tecnologias Utilizadas

* MySQL
* MySQL Workbench
* Power BI Desktop
* Power Query

Etapas Realizadas

* Instalação e configuração do MySQL.
* Importação dos dados para o banco de dados.
* Conexão do Power BI com o MySQL.
* Tratamento e validação dos dados.
* Mescla de tabelas por chave comum.
* Expansão de colunas provenientes das tabelas relacionadas.
* Ajuste de tipos de dados e validação de registros.
* Criação de indicadores e visualizações analíticas.
